I'm a frontend-focused full-stack engineer with around 4 years of experience building production web applications.

Most of my work lives around **React**, **Next.js**, **TypeScript**, **Node.js**, and commerce/product engineering. I care about the parts users feel immediately: loading speed, UX, accessibility, responsive behavior, reliability, and whether the thing actually makes sense to use.

I also enjoy the less glamorous parts: debugging hydration issues, cleaning up state flow, reducing repeated API calls, improving component boundaries, and making future-me slightly less angry.

## Debugging philosophy

```txt
1. Reproduce the bug.
2. Doubt everything.
3. Check the network tab.
4. Check the state.
5. Check the CSS.
6. Blame hydration.
7. Discover it was a missing dependency array.
8. Stare into the void.
9. Fix it properly.
```
